# PCS Feature Standard

Every feature must contain:

Feature
│
├── components
│     FeatureKPIs.tsx
│     FeatureToolbar.tsx
│
├── dialogs
│     FeatureDialog.tsx
│
├── hooks
│     useFeature.ts
│
├── pages
│     Feature.tsx
│     FeatureTable.tsx
│
├── services
│     feature.service.ts
│
├── types
│     feature.ts
│
└── index.ts

Rules

✔ one hook

✔ one service

✔ one dialog

✔ one table

✔ one page

✔ one model

✔ one index
